# Gallinas a la Fuga — Modelos

Modelos 3D, rigs y animaciones (Blender / FBX) de *Gallinas a la Fuga*.

## Cómo colaborar

1. Instala [Git](https://git-scm.com/) y [Git LFS](https://git-lfs.com/) (`git lfs install`).
2. Clona: `git clone https://github.com/BeatrizAligh/gallinas-modelos.git`
3. **Antes de tocar cualquier archivo:** `git pull`
4. Al terminar: `git add .` → `git commit -m "qué cambiaste"` → `git push`

Los `.blend` y `.fbx` son binarios y **no se pueden fusionar**: avisa al grupo antes
de editar un archivo para que dos personas no trabajen el mismo a la vez.

## Carpetas

- `Gallina/`, `Gavilan/` — personajes animales con rig y animaciones
- `Personajes/` — granjeros
- `Girasoles/`, `Mazanos/` — vegetación animada
- `Props/` — objetos
- `*.py` — scripts de Blender CLI
